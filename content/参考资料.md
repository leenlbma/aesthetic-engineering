## 本系列怎样使用术语

**Aesthetic Engineering / 审美工程**：本系列对组织创作判断的工作方法的称呼。它把描述、参考、方向、生成、评审与记忆放到一起讨论，不主张这些工作由本文首次发明，也不将六层结构当作已经验证的技术标准。

**Taste / 审美判断**：在具体任务中对表达、关系和取舍的判断。它与个人偏好有关，也受目标、文化、媒介和约束影响。文中同时区分个人喜欢、任务适配和实际效果。

**Aesthetic Stack / 六层结构**：一种职责划分。同一个人、工具或模型可以承担多项职责，不要求六个独立模块。

**Aesthetic Critic / 审美评审机制**：结合实际作品与任务提出观察、解释和建议。它的建议需要检查，不能仅凭解释流畅就认为可靠。

**Aesthetic Eval / 审美评测**：对作品质量及评审可靠性的检验。评审机制与检验评审机制是否可靠，是相关但不同的工作。

**Aesthetic Gradient / 审美梯度**：第三篇用作修改方向的比喻，不是数学梯度或新算法。需与上表中的同名研究区分。

**Taste Spec、Direction Contract、Generation Protocol**：分别用于保存默认选择、约定当前方向、组织一轮生成比较的工作记录。它们没有统一的行业字段规范，文中的模板可以按任务调整。

**Taste Memory / 审美记忆**：保存选择经历、提出可修正的偏好假设，并说明当前允许怎样调用。参考系统管理可借鉴的证据，两者可以共享素材与记录。

**Brand Taste Model / 品牌审美模型**：文中可以指判断表示、案例与工作流程。是否需要训练参数模型，是另一项需要根据实际问题决定的工作。

这些说明用于减少误读。可迁移的判断需要通过新任务继续检验，命名本身不构成有效性的证明。
