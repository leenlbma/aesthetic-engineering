# 六层概念索引

本页依据 LeenMa 的 12 篇文章整理，用于定位概念和对应原文。定义是阅读摘要；应用前应读取相关篇目，并结合任务检查。

## 总体关系

审美工程组织的是创作判断：把感受描述清楚，为选择准备依据，明确本轮方向，产生可比较的候选，再通过评审和经验记录修正下一次工作。

六层的典型连接可以读作：**描述差异 → 组织参考 → 确定方向 → 生成候选 → 比较与修改 → 记录经验**。实际工作会回退和往返；相关记忆回到方向与评审，新输出也可能推翻原来的方向假设。

框架总览见 [第三篇](../content/03-Aesthetic-Engineering-我们能把审美工程化吗.md)，适用边界见 [第十二篇](../content/12-边界与未来.md)。

## 01 · Taste Language / 审美语言

- **处理的问题**：把“高级一点”“太 AI”等感觉拆成可以讨论的差异。
- **输入**：作品、任务目标、人的感受，以及比较时注意到的关系。
- **产物**：关于构图、密度、色彩、字体、材质、节奏、文化语境等维度的描述；说明偏好与边界。
- **交给下一层**：让参考检索知道要寻找什么关系，让方向约定有可解释的词汇。
- **边界**：描述维度不能直接算出“最美答案”；低饱和、留白或颗粒没有通用的优越性。

来源：[第四篇《审美语言》](../content/04-审美语言.md)，尤其第六、八、九节。相关记录：**Taste Spec**，用来保存有范围、可修订的默认选择。

## 02 · Reference System / 参考系统

- **处理的问题**：让参考图带着可调用的依据，而不只是堆进收藏夹。
- **输入**：正例、近邻反例、来源、选择理由、任务与使用条件。
- **产物**：说明“借什么、不借什么”的参考证据与候选组合。
- **交给下一层**：支持当前项目确定方向，保留可以回看的出处与解释。
- **边界**：视觉相似不能替代判断；参考系统准备证据，当前项目的最终优先级由艺术指导决定。

来源：[第五篇《参考系统》](../content/05-参考系统.md)。相关概念：**Reference Atom**，把可复用的局部关系与其解释、来源、职责一起保存。

## 03 · Art Direction / 艺术指导

- **处理的问题**：这次为什么做、往哪里走，以及冲突时优先保护什么。
- **输入**：意图、受众、媒介、品牌与任务约束、参考证据。
- **产物**：可检查的方向假设，固定项、开放项、边界和优先级。
- **交给下一层**：让生成围绕明确问题展开，让评审知道依据什么比较。
- **边界**：选一个风格标签不能替代方向；方向也可能被实际结果推翻和更新。

来源：[第六篇《艺术指导》](../content/06-艺术指导.md)。相关记录：**Direction Contract**，约定当前任务中的判断依据；**Creative Brief** 主要说明任务本身。

## 04 · Generation Protocol / 生成协议

- **处理的问题**：怎样让一轮生成回答问题，候选之间可以比较。
- **输入**：方向约定、本轮待检验的问题、参考、预算与执行条件。
- **产物**：候选版本、变化记录、执行问题，以及继续、编辑、回退或停止的决定。
- **交给下一层**：保留可核对的实际输出与条件，帮助评审区分方向问题和执行问题。
- **边界**：多生成不自动增加有效信息；同时改变多个条件会影响归因，相同 Seed 也不保证全面复现。

来源：[第七篇《生成协议》](../content/07-生成协议.md)。第三篇总览将这一层称为 **Generation / Renderer**；这里进一步说明它的工作组织方式。

## 05 · Aesthetic Critic / 审美评审

- **处理的问题**：作品中什么值得保留，哪里影响当前目标，下一步怎样改。
- **输入**：实际作品及展示条件、目标、优先级和参考职责。
- **产物**：可核对的观察、有条件的解释与判断、修改建议和保护范围。
- **交给下一层**：记录选择理由、采用或推翻了哪些建议，以及修改后的证据。
- **边界**：评分不能替代取舍；流畅解释不能证明可靠；交付错误与方向价值应分别处理。

来源：[第八篇《审美评审》](../content/08-审美评审.md)。**Aesthetic Eval** 指检验作品与评审可靠性的工作，和参与评审的 Critic 有区别。

## 06 · Taste Memory / 审美记忆

- **处理的问题**：把经验带到下一次，同时允许人改变偏好、修正系统理解。
- **输入**：任务与版本、实际选择、理由来源、保留与修改、后续反馈。
- **产物**：分别保存的原始经历、可被推翻的偏好假设、当前适用的约定。
- **反馈到前面**：在相似任务中辅助方向与评审，并说明沿用什么、哪些条件不同。
- **边界**：一次采用不等于长期授权；当前明确要求优先于历史默认；未被展示的选项也影响对偏好的解释。

来源：[第九篇《审美记忆》](../content/09-审美记忆.md)，尤其第三、四、五节。

## 容易混淆的概念

| 概念 | 在本系列中的含义 | 不应直接推导出的结论 |
| --- | --- | --- |
| Taste | 在任务、身份、文化和约束中的审美判断与取舍 | 喜欢某种外观，就一定适合所有任务 |
| Aesthetic Gradient | 第三篇对“修改方向”的比喻 | 已提出数学梯度或新的同名算法 |
| Taste Spec | 可复用但有适用范围的默认选择 | 不允许当前任务改变的永久规则 |
| Direction Contract | 当前项目中可以检查和更新的方向约定 | 生成前已经拥有最终答案 |
| Brand Taste Model | 品牌判断表示、案例或工作方式 | 必须训练一个专属参数模型 |
| Concept Formula | 用符号强调相互关系 | 可以代入数值计算或直接证明因果 |

品牌原则跨项目使用见 [第十篇](../content/10-品牌审美.md)；多人分歧与判断责任见 [第十一篇](../content/11-团队协作.md)。研究术语和支持范围应继续核对 [参考资料](../content/参考资料.md)。
