# 三个任务示例

以下模板依据 LeenMa 的文章整理，供读者与 AI 在具体项目里试用。字段和示例属于应用整理，不是行业标准，也不代表实际实验结果。

三个任务可以连接起来：先明确方向，再比较实际候选，最后修改与回看。已有候选时，也可以从评审开始。

## 任务一：比较作品，说明为什么暂选某一版

**先读**：[第四篇](../content/04-审美语言.md)、[第六篇](../content/06-艺术指导.md)、[第八篇](../content/08-审美评审.md)。

**最小输入**：真实候选及版本、受众和媒介、实际展示尺寸、本轮优先级、必须满足的约束。没有作品时，只能整理评审约定；不能从生成提示猜测成品。

可直接填写的请求：

```text
请依据审美工程第四、六、八篇，比较我提供的候选 A 与 B。
用途与展示条件：［填写］
本轮最重要的问题：［填写］
必须满足的约束：［填写］
允许的修改时间与范围：［填写］

先描述实际可见的差异，再结合任务解释影响。
分别说明每版值得保留的关系、最重要的问题与对应证据。
区分“当前能否交付”和“方向是否值得继续”。
给出有条件的暂选建议，也可以建议两版都不采用。
最后提出本轮最值得做的一项修改、保护范围，以及会改变建议的新证据。
```

**建议输出**：

| 项目 | 要写清楚什么 |
| --- | --- |
| 已见材料与未知 | 读到了哪些作品；哪些细节或条件尚不能核对 |
| 观察 | 指出画面位置、文字、动作或空间关系；视频证据需标时间段 |
| 解释 | 差异可能怎样影响当前目标，哪些仍是假设 |
| 判断 | 在当前优先级下怎样取舍；交付状态与方向价值分别说明 |
| 下一步 | 一项优先修改、必须保留的关系、回看条件 |
| 方法来源 | 使用了哪篇文章、哪一节的方法 |

**示意**：假设真实画面已经核实，A 的人物在整理一列卡片，B 的人物把一张卡片放入独立区域。本轮目标是表达“选择”，且有时间修复 B 的局部接触问题。可以暂选 B 继续修改，同时保留“在缩略图中仍能读出取舍”的条件。这是第八篇示意案例的应用；没有核实图像时，不能把这些观察用于用户实际的 A 与 B。

## 任务二：在生成之前，写出可以检查的方向

**先读**：[第五篇](../content/05-参考系统.md)、[第六篇](../content/06-艺术指导.md)；安排生成时继续读 [第七篇](../content/07-生成协议.md)。

**最小输入**：传播或表达目标、受众、媒介、必要文字或商品事实、品牌约束、可用素材。参考应说明借什么、不借什么。

可直接填写的请求：

```text
请依据审美工程第五至七篇，为这次任务整理创作方向。
目标、受众与媒介：［填写］
必须准确保留的信息：［填写］
参考及其职责：［填写］
品牌约束与可探索范围：［填写］
时间或成本约束：［填写］

输出一份简短的方向约定：任务目标、方向假设、核心关系、
参考职责、固定项、开放项、优先级与检查条件。
再建议首轮应比较的差异，并记录本轮保持不变的条件。
信息不足时，列出影响方向的关键未知；所有补充设想都标为待确认。
```

**方向约定示意**：假设任务是制作“AI 展开可能，人决定留下什么”的系列封面。

| 字段 | 一种待检验的方向 |
| --- | --- |
| 目标 | 让“取舍”这个关系能被看见 |
| 方向假设 | 人的动作改变一张候选与其他候选的位置关系 |
| 固定项 | 已确认的标题、必要署名；必须保留多个候选与一个选择后果 |
| 开放项 | 卡片、物体或其他隐喻；具体媒介、视角与材质待比较 |
| 参考职责 | 一张参考借阅读层级，另一张借动作关系；不直接复制其人物与内容 |
| 优先级 | 信息准确、核心关系可读，之后再讨论材质完成度 |
| 检查条件 | 实际展示尺寸下是否可读；读者检查是否支持该解释 |

这张表提供的是方向假设。未生成作品前，不能写成“已证明这个构图有效”。若输出只让人看见整理，就需要调整关系或回退方向。

## 任务三：把评语变成可检验的修改，并记录经验

**先读**：[第七篇](../content/07-生成协议.md)、[第八篇](../content/08-审美评审.md)、[第九篇](../content/09-审美记忆.md)。

**最小输入**：修改前作品、当前约定、已接受的评语、必须保护的优点和可用编辑方式。修改后的判断需要实际新版本。

可直接填写的请求：

```text
请把下面的评语整理成下一轮修改计划：［填写评语］。
当前作品与版本：［提供］
已经成立、必须保护的关系：［填写］
可用工具与编辑范围：［填写］

给出具体动作、影响位置、保护范围和修改后的检查条件。
说明为什么先做这一项，以及什么情况需要回退方向或停止。
现在只有修改前版本时，先输出计划，不要宣称修改已经有效。
收到修改后版本，再比较前后证据，并记录采用、推翻或仍待验证的建议。
```

**把模糊评语改成行动的示意**：

“画面太满”可以进一步写成：“如果背景卡片确实在争夺注意，先降低它们的线条对比；保留候选集合与被选对象的分离关系。修改后在实际尺寸下检查被选对象是否更容易找到，同时确认‘从多个候选中选择’仍然可读。”

它指出一个条件性解释和一项可尝试的动作，并没有预先保证修改有效。

**回看记录建议**：

- 原始经历：任务、前后版本、实际采取的动作与当时的选择。
- 理由来源：用户原话、AI 推断或后续核对，分别标明。
- 保留与修正：优点是否保住，哪些问题仍然存在。
- 偏好假设：这次结果是否支持某种有范围的理解；有哪些其他解释。
- 当前约定：仅用于本次、可用于系列，还是尚未确认。
- 未知与后续：还需要什么证据，什么会改变当前决定。

例如，“这次暂选 B 但要求修手部”可以是一次经历；“用户永远喜欢 B 的全部风格”不能由此成立。没有明确的长期约定时，不把记录自动提升为长期偏好。

## 三个任务共同的完成条件

回答应能让下一位创作者知道：依据是什么、准备做什么、什么要保留、怎样回看。引用相关篇目；未知材料留为未知；用实际作品与后续反馈检查建议，而不是把流程完成当作效果证明。
